# CrashVector 0.9.0-beta.10

This corrective M23 desktop beta is a production-readiness hardening release. It does not add manufacturer-specific crashworthiness claims; it tightens the role-neutral rigid-body path, replay/analysis integrity, vehicle dynamics and editor capability boundaries introduced during M23.

- Vehicle start preflight now uses oriented geometry envelopes, rejecting overlapping vehicle starts before simulation.
- M23 replay/analysis now records real contact counts, actor-specific deformation/articulation metrics and role-neutral loading/deformation terminology instead of assuming a passenger-car front crush or safety cell.
- Articulated truck contact material, fixed-fixture collision mass and tank primary/target semantics are applied consistently across the shared production world.
- Collision-demand estimation uses immediate pre-impact/contact-entry motion rather than restoring scenario-start speed after vehicles have already accelerated, braked or exchanged momentum.
- Passenger-car supplemental crush resistance acts at the observed contact point, preserving the lever-arm torque of offset/oblique contacts.
- Heavy truck, rigid lorry and articulated tractor/trailer bodies use explicit neutral mass/inertia envelopes so crush-shell resizing does not redefine rotational inertia during a crash.
- Dynamic-tank road support is separated from rigid track collision support and covered by flat-road suspension/roll/pitch regressions.
- Passenger wheel release/spin, rotated wheel placement, motorcycle rider release and articulated state are preserved more faithfully in replay.
- M23 camera framing and the editor selection marker use actual actor geometry, including asymmetric articulated-truck origins.
- The editor now follows the same target capability matrix as the production runtime and hides or disables passenger-car-only controls for non-passenger primaries.
- A dedicated M23 production-matrix regression covers all supported non-passenger primary/vehicle-or-fixture target combinations and explicitly rejects unsupported vulnerable-road-user pairings.

CrashVector remains an educational visualisation. Pedestrian, bicycle, cyclist and motorcycle-rider behaviour is not a biomechanics or injury model; heavy-vehicle/tank deformation and articulation remain generic educational approximations rather than manufacturer or regulatory validation.
