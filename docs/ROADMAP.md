# Roadmap

## M0 — Physics skeleton

- Godot project bootstrap.
- 240 Hz fixed physics tick.
- Configurable rigid test vehicle.
- Rigid road/barrier scene.
- Telemetry recorder.
- Kinetic-energy and momentum diagnostics.
- Headless smoke tests and CI.

## M1 — Structural proof

- Structural node type.
- Beam connectivity and rest length.
- Elastic response and damping.
- Plastic yield and permanent deformation.
- Failure thresholds and broken-beam state.
- Structural debug renderer.
- Energy-balance diagnostics.

## M2 — Compact hatchback

- Generic B-segment body structure.
- Passenger safety cell.
- Crush zones.
- Wheels/suspension approximation.
- Exterior-mesh deformation mapping.
- Detachable non-structural parts.

## M3 — Heavy truck

- Generic tractor/trailer.
- Configurable gross mass.
- Truck collision geometry.
- Car-vs-truck reference scenarios.

## M4–M8

M4 adds the scenario editor; M5 analysis/replay; M6 synchronized comparison; M7 video export; M8 documented calibration and validation ranges.
