# CrashVector 0.9.0-beta.2

`0.9.0-beta.2` is the current public M22 desktop beta. It preserves the M19–M22 functionality released in `0.9.0-beta.1` and corrects the Windows installer SHA-256 sidecar to use a portable LF line ending.

## Release contents

- completed M22 production stack, including the M19 contact diagnostics, M20 heavy/other-vehicle deformation, M21 articulated heavy truck and M22 cyclist/moving-pedestrian support;
- full M0–M22 Godot regression validation, production visual/contact review and native macOS/Windows package checks completed before release;
- macOS Universal 2 DMG and Windows x64 Setup installer;
- portable SHA-256 sidecars and `update-manifest.json` for updater verification.

## Package integrity

The Windows installer sidecar is written with a single LF-terminated checksum record so common Unix and Windows verification tools parse the filename consistently. This is a packaging-only correction; it does not alter the simulation's production behaviour or modelling boundaries.

## Scope

CrashVector remains an educational simulation. Its generic M19–M22 models are not certified accident reconstruction, manufacturer crashworthiness, biomechanics, injury prediction or regulatory validation.
