# CrashVector 0.2.0-beta.1

M10 is a visual and UX rebuild over the existing CrashVector simulation stack. The release intentionally preserves the M0–M9 structural solver, scenario format, replay/analysis, comparison, calibration, cinematic export and updater semantics while replacing the crowded desktop presentation.

## What changed

- New responsive desktop shell with separate Scenario and Compare workspaces.
- Compact scenario setup and tabbed Vehicle, Target, Physics and Appearance inspector.
- Collapsible replay/analysis drawer that reserves space instead of covering the 3D viewport.
- First-run ready example: generic B-class passenger car versus rigid wall at 50 km/h.
- Reworked generic passenger-car presentation with body paint, glazing, lamps, trim and class-scaled silhouettes, still driven by the same deformable structural graph.
- Reworked generic articulated truck, rigid lorry, motorcycle and bicycle presentation.
- Clearer static wall, barrier, pole and tree presentation plus a technical road/lighting environment.
- Existing Updates, Calibration, Video and Comparison Lab services remain in their original M7–M9 ownership hierarchy and are launched from the new shell.
- Dedicated editor and responsive-layout CI checks cover 1280×720 through 2560×1440 and reject the overlap failure mode that motivated M10.

## Physics and evidence scope

M10 does not introduce a new physics engine or broaden CrashVector's validation claim. Generic vehicle classes are still class-level approximations rather than production models. High-speed, heavy-vehicle, motorcycle, bicycle and pedestrian scenarios retain the evidence classifications and limitations documented in `docs/CALIBRATION.md` and `docs/PHYSICS.md`. Pedestrian output remains an articulated contact/trajectory proxy, not an injury model.

## Packaging

The release uses the M9 desktop distribution architecture:

- `CrashVector-0.2.0-beta.1-macOS-universal.dmg`
- `CrashVector-0.2.0-beta.1-macOS-universal.dmg.sha256`
- `CrashVector-0.2.0-beta.1-Windows-x64-Setup.exe`
- `CrashVector-0.2.0-beta.1-Windows-x64-Setup.exe.sha256`
- `update-manifest.json`

macOS remains ad-hoc signed/unnotarized and Windows unsigned unless the corresponding signing credentials are configured in CI. See `docs/DISTRIBUTION.md` for install, removal, update and signing details.
