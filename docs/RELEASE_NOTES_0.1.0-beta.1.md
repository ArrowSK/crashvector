# CrashVector 0.1.0-beta.1

This is the first packaged desktop beta of CrashVector.

## Included

- M0–M8 simulation, replay, analysis, comparison, cinematic export, calibration scope, expanded vehicle library, bicycle and pedestrian proxies.
- M9 desktop-product lifecycle.
- Normal macOS DMG installation and removal through Applications/Finder.
- Normal Windows installer and Apps & Features uninstaller.
- Built-in update checker/downloader with SHA-256 verification and system-installer handoff.
- High-resolution application branding and native macOS/Windows icons.
- Explicit no-runtime-monkey-patching architecture contract and CI check.

## Packaging status

The macOS beta is ad-hoc signed but not Developer-ID signed/notarized. The Windows beta is not Authenticode-signed. Both systems may therefore display first-run publisher/security warnings.

CrashVector remains an educational physics visualisation tool. It is not certified accident reconstruction, homologation, manufacturer crash-performance prediction, biomechanics, injury prediction, or a safety-rating system.
