# CrashVector 0.9.0-beta.4

`0.9.0-beta.4` is a corrective M23 desktop beta. It keeps the M19–M23 simulation design intact while repairing the passenger-car presentation defects reported in the released build.

## Release contents

- passenger-car bodies continue to use the Kenney source geometry, while all four visible wheels use the existing structural-anchor wheel rig; a nested imported-wheel mesh offset can therefore no longer detach a wheel from its suspension position;
- setup, live and aftermath cameras reserve a full-car-and-target envelope, so wheels and fast post-impact movement do not disappear through a tight presentation crop;
- the orange world-space selection ring is removed from the scenario viewport because the Properties tabs already communicate selection and the ring was being mistaken for a scene object;
- all existing M23 support remains: safe repeated runs, bounded road support, target-car broadside collapse, bounded pedestrian response and the generic tank fixture.

## Validation

- Godot import and parse validation;
- targeted visual, runtime stability, packaged-scenario, reciprocal-impact and long-road regression checks;
- semantic-version/updater validation;
- GitHub release packaging validates macOS Universal 2 and Windows x64 installers, checksums and the generated update manifest before publication.

## Scope

CrashVector remains an educational simulation. This corrective release improves presentation consistency and scenario visibility; it does not claim certified accident reconstruction, manufacturer crashworthiness, biomechanics, injury prediction or regulatory validation.
