# CrashVector 0.9.0-beta.3

`0.9.0-beta.3` packages the M23 runtime stability and presentation corrections. It retains the completed M19–M22 production stack and the generic, educational modelling boundaries of earlier v0.9 betas.

## Release contents

- a fresh simulation run is started from the completed-state **Run again** action, while comparison mode remains protected;
- legacy bumper visuals are hidden, imported wheel alignment correction is bounded, and passenger-car wheels remain visually anchored to their suspension positions;
- the road uses a 20 m asphalt strip with a 600 m grass support plane so high-speed and side-impact trajectories remain on a physical surface;
- live and replay cameras frame the active primary and target bodies, including heavy vehicles and fast post-impact separation;
- pedestrian contact impulses are shared across the articulated proxy so no single segment receives the prior rocket-like impulse;
- a stationary passenger-car target now receives bounded protected-cell side-collapse when a production front-crush probe enters its broadside, and its collision face retreats with the deformation;
- a generic fixed tank target is available with hull and turret collision volumes and a visual-only, non-colliding main gun.

## Validation

- architecture audit and import/parse validation;
- full Godot regression suite, including reciprocal impacts, long-road support, runtime presentation stability, passenger-car side impacts, heavy targets and articulated road users;
- macOS Universal 2 DMG creation, bundle/signature checks and SHA-256 verification;
- Windows x64 installer creation, install/uninstall verification and SHA-256 verification;
- release-side checksum verification and generated `update-manifest.json`.

## Scope

CrashVector remains an educational simulation. The tank is a generic static fixture; the new presentation and deformation behaviour does not provide certified accident reconstruction, manufacturer crashworthiness, armour/ballistic modelling, biomechanics, injury prediction or regulatory validation.
