# CrashVector

Open-source educational 3D vehicle collision simulator with physically informed deformation, crash analysis, replay and video export.

> CrashVector is an educational physics visualisation tool. It is not a certified accident-reconstruction, vehicle-homologation, structural-engineering, or occupant-injury prediction system.

Development has started with **M0 — Physics Skeleton**: deterministic fixed-step simulation, a configurable rigid test vehicle, barrier impact, telemetry, and energy/momentum diagnostics.
