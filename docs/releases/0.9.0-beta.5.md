# CrashVector 0.9.0-beta.5

`0.9.0-beta.5` is a corrective M23 desktop beta. It preserves the existing simulation and workflow while fixing the passenger-car wheel placement and making the generic tank target visibly recognisable and reliably collidable.

## Release contents

- passenger-car bodies retain the CC0 Kenney Car Kit source geometry; the established CrashVector wheel mesh and spin rig now place each wheel at the matching named source-body wheel centre through the same pristine/deformation transform as the body, so the visual wheelbase, track and ride height match the selected body;
- the generic tank is rebuilt as original CrashVector tracked-vehicle geometry: hull, tracks, road wheels, turret, hatch and a visible non-colliding main gun, without representing a specific real vehicle model;
- the tank collision hull now starts at the visible front hull face and uses the same dimensions in the static contact model, so front impacts register and produce normal CrashVector crush/contact behaviour;
- the existing M23 corrections remain: repeatable runs, bounded road support, target-car broadside collapse, bounded pedestrian response and adaptive camera framing.

## Validation

- Godot project import and parse validation;
- targeted Kenney passenger-car source-body wheel-fit regression, including body-envelope placement checks;
- production reciprocal-impact/tank-contact regression with a real rigid-body front probe contact and measurable crush;
- heavy and other-target collision regression;
- semantic-version/updater validation;
- GitHub release packaging will validate macOS Universal 2 and Windows x64 installers, checksums and the generated update manifest before publication.

## Asset and modelling scope

Kenney Car Kit remains CC0 and is recorded in the third-party notices. The improved tank is original generic CrashVector geometry under the repository licence. CrashVector remains an educational simulation: this release does not claim certified accident reconstruction, manufacturer crashworthiness, biomechanics, injury prediction or regulatory validation.
