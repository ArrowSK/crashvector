# CrashVector branding

`crashvector-icon.webp` is the canonical application and repository artwork. It is a 512×512 crop made from the large source icon in the supplied logo sheet; do not upscale any of the small preview icons.

Platform-specific icon resources are derived from this source during packaging. The Windows build produces a multi-resolution ICO, while the macOS export consumes the same high-resolution artwork for its native application icon.
