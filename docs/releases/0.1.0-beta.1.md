# CrashVector 0.1.0-beta.1

This is the first packaged desktop beta of CrashVector.

It preserves the M0–M8 simulation, replay, comparison, calibration and cinematic-export functionality while adding the M9 desktop-distribution layer.

## What is new

- Native macOS Universal 2 application packaged in a drag-to-Applications DMG.
- Native Windows x64 application packaged with a standard Inno Setup installer and uninstaller.
- CrashVector application identity/version metadata in the packaged builds.
- Built-in **Updates** UI using official CrashVector GitHub Releases.
- Manual update checking plus an optional once-daily automatic check.
- Semantic-version handling for beta-to-beta and beta-to-stable upgrades.
- Release-note preview before download.
- Deterministic platform package selection through `update-manifest.json`.
- SHA-256 verification before an installer can be opened.
- Safe OS handoff: macOS opens the verified DMG; Windows launches the verified Setup executable; CrashVector never overwrites its running executable.
- Separate Core CI, macOS-package and Windows-package validation gates.
- CI architecture audit preventing runtime script/resource monkey patching.
- Deterministic native icon generation from the existing high-resolution CrashVector SVG master.

## Existing capability retained

The beta retains the generic A/B/C/D/J/M passenger-car classes, supported car-vs-car and heavy-vehicle scenarios, riderless motorcycle/bicycle and pedestrian proxies, static targets, arbitrary speeds including exact 130 vs 140 km/h comparison, Comparison Lab, recorded replay, Δv/crash-pulse/deformation analysis, presentation colours, evidence labels and cinematic video export.

## Signing note

The release pipeline can use Apple Developer ID/notarization and Windows Authenticode credentials when they are configured. In their absence, the first beta is ad-hoc signed on macOS and unsigned on Windows. Gatekeeper or SmartScreen can therefore warn about an unknown/unnotarized developer. Download packages only from the official `ArrowSK/crashvector` GitHub Release; SHA-256 sidecars are supplied for both installers.

## Scope

CrashVector remains an educational physics visualisation tool. It is not certified accident reconstruction, homologation, manufacturer crash-performance prediction, biomechanics, medical/injury prediction or a safety-rating system.
