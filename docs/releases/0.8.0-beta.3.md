# CrashVector 0.8.0-beta.3

This corrective beta packages two fixes that were merged after `0.8.0-beta.2` had already been published. The previous `0.8.0-beta.2` installers therefore could not contain them.

## Working Updates modal

The M9 updater modal is now placed above the current M10/M16 desktop layer and fitted to the active viewport. This fixes the case where the modal was visible but its controls were underneath the desktop and could not reliably receive clicks.

The existing updater hierarchy, network/update service, checksum verification and installer handoff are preserved. The focused M10 regression opens Updates at 1280×720, verifies the modal stays on-screen and above the desktop, and verifies the **Check for updates** button remains enabled and interactive.

## Kenney Car Kit passenger-car presentation

Passenger-car presentation now uses the pinned **Kenney Car Kit 3.1** asset source for the six generic CrashVector passenger-car classes:

- A-segment city car: `hatchback-sports.glb`
- B-segment small hatchback: `hatchback-sports.glb`
- C-segment compact car: `sedan.glb`
- D-segment midsize car: `sedan-sports.glb`
- J-segment SUV/crossover: `suv.glb`
- M-segment MPV/minivan: `van.glb`

Passenger cars use Kenney `wheel-default.glb` for presentation wheels. Existing CrashVector paint selection remains active.

The Kenney meshes are presentation only. They are remapped onto the existing deforming M16.2 structural presentation cage, so M12/M13 front crush, M17 rear crush and M18 lateral intrusion still drive visible deformation. Mass, rigid-body motion, collision geometry, structural state, contact impulses, replay and analysis are unchanged.

The pinned Car Kit source is CC0 and its provenance is recorded in `THIRD_PARTY_NOTICES.md` and `docs/KENNEY_CAR_KIT.md`. Packaging initialises the pinned submodule and fails if the required assets are incomplete instead of silently shipping the procedural development fallback.

Heavy articulated truck, rigid lorry, motorcycle, bicycle and pedestrian presentation remains purpose-built because the Car Kit does not contain semantically appropriate equivalents for those simulated classes.

## Regression coverage

This release retains all existing M12–M18 production regressions and adds/uses focused checks for:

- updater modal layering, viewport fit and button interactivity;
- all six passenger-car Kenney mappings;
- required Kenney body/wheel asset availability;
- production-scene Kenney activation;
- four authoritative wheel-anchor attachments;
- existing CrashVector paint selection;
- front, rear and lateral structural-deformation coupling;
- passenger-car class rebuild to the corresponding Kenney asset.

## Modelling and evidence scope

CrashVector remains an educational physics visualisation tool. This release does not add manufacturer-specific crash stiffness, certified accident reconstruction, homologation, occupant biomechanics, medical/injury prediction or safety-rating capability.

## Desktop packages

The canonical release pipeline builds and verifies:

- `CrashVector-0.8.0-beta.3-macOS-universal.dmg` plus SHA-256 sidecar;
- `CrashVector-0.8.0-beta.3-Windows-x64-Setup.exe` plus SHA-256 sidecar;
- `update-manifest.json` containing the exact package filenames, sizes and hashes.

Existing `0.8.0-beta.2` installations are eligible to discover `0.8.0-beta.3` through the prerelease updater once this release is published.
