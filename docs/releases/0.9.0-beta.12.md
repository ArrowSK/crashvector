# CrashVector 0.9.0-beta.12

This desktop beta finalises the presentation-hardening series on top of the existing M23/M24 production architecture. It improves how the generic vehicles and riders read on screen and turns the new presentation contracts into release-blocking regressions. The underlying collision, mass, structural-deformation and rider/cyclist coupling authority is unchanged.

- Passenger-car Kenney bodies now fit the public A/B/C/D/J/M class dimensions axis-by-axis, preserving the established production front contact face while keeping the existing class-specific height envelope. Rendered class order is regression-tested.
- Passenger-car materials retain the pinned Kenney assets while improving body paint, glass, trim, lamps and wheel presentation without changing collision or deformation geometry.
- The articulated heavy truck now has recognisable, separate tractor and trailer presentation roots. The tractor uses the pinned CC0 Kenney truck body fitted to the existing M21 structural envelope; the trailer and fifth-wheel details remain CrashVector-authored.
- The motorcycle presentation is rebuilt around rounded/tubular body parts that follow the existing structural stations. Its visual-collapse regression now measures rendered geometry independently of the structural model, preventing a false-green presentation test.
- Motorcycle wheels now use open tyre/rim rings and eight true radial spokes from hub to rim instead of solid discs with buried centred bars.
- The motorcycle rider keeps the same two authoritative rigid bodies and contact-triggered release, but gains an articulated presentation-only pelvis/arms/legs/boots/gloves skin. The seated hand positions are regression-tested against the actual handlebar grip meshes.
- The cyclist keeps the existing eleven rider rigid bodies and five temporary bicycle couplings. The visible pelvis follows the physical `CyclistPelvis`, and pre-impact hands/feet follow the established bicycle coupling anchors.
- A strict cross-target visual QA gate now makes passenger dimensions, articulated-truck roots/fifth-wheel gap, motorcycle tube/wheel geometry, rider hand-to-grip placement and cyclist body-bound anchors mandatory. Removing those contracts must fail CI rather than silently disabling the check.
- The native release workflow now includes both passenger-material and cross-target visual-presentation regressions in its publishable validation path.

Validation for this release includes the consolidated M0-M23 regression stack, the focused passenger material, motorcycle contact/deformation, articulated-truck, cyclist/moving-pedestrian and strict visual-presentation gates, followed by the normal macOS Universal 2 and Windows x64 package/install/checksum/update-manifest checks.

CrashVector remains an educational visualisation. The generic classes and rider/vehicle presentations are not manufacturer geometry, crashworthiness, biomechanics, injury prediction, regulatory validation or forensic reconstruction.
